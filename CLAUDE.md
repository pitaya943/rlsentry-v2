# rlsentry-v2

## shilaycow harness

This repository runs the shilaycow harness. Its settings are in `.shilaycow/config.yml`.

Standing permission from the owner (pitaya943):

- Agents may create and push `task/`, `work/`, `spike/` and `chore/` branches, and the setup branch `setup/shilaycow`.
- Agents never push to `main`. `main` changes only through a pull request.
- Only the owner merges into `main`.
